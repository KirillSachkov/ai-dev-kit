# Скиллы

Скилл содержит инструкции для агента под конкретную задачу. Здесь два скилла, которые можно использовать независимо.

| Скилл | Когда нужен |
|---|---|
| [sachkov-ai-kit](sachkov-ai-kit/SKILL.md) | Найти материал, выбрать инструменты и понять сетап Кирилла |
| [setup-ai-stack](setup-ai-stack/SKILL.md) | Установить выбранные инструменты или адаптировать конфиги |

Для первого знакомства используй главный скилл. Он учитывает твою задачу и направляет к нужному разделу. Если ты уже выбрал инструменты, можно сразу использовать скилл настройки.

## Запуск из репозитория

Открой папку набора в агенте. Укажи путь к нужному `SKILL.md` в запросе. Устанавливать скилл для такого запуска не требуется.

## Установка скиллов

Если хочешь вызывать скиллы из других проектов, попроси своего агента установить выбранные папки из `skills/` через поддерживаемый им механизм. У каждого скилла есть собственная папка `references/`, которую нужно переносить вместе с `SKILL.md`. [agents/openai.yaml](sachkov-ai-kit/agents/openai.yaml) содержит название и пример запроса для интерфейса Codex.

После установки отдельно от репозитория главный скилл сохраняет контекст автора и основного стека. Для рекомендаций агент может прочитать публичный репозиторий. Для переноса конфигов укажи путь к клону или попроси скилл настройки получить набор. Копия скилла сама по себе не содержит конфиги.

Пример запроса для установленного главного скилла:

```text
Используй $sachkov-ai-kit. Набор находится в ~/Projects/ai-dev-kit.
Помоги выбрать инструменты для нескольких параллельных задач.
```

## Добавить свой скилл

Создай папку с коротким названием и `SKILL.md` с полями `name` и `description`. Дополнительный контекст помещай в её `references/`, чтобы скилл оставался переносимым. Добавь ссылку и назначение в таблицу выше.
