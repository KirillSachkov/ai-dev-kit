# Контекст набора

Автор: Кирилл Сачков. [YouTube](https://www.youtube.com/@SachkovDev), [Telegram](https://t.me/sachkov_blog), [GitHub](https://github.com/KirillSachkov).

[Публичный репозиторий](https://github.com/KirillSachkov/ai-dev-kit) содержит полный набор.

AI Dev Kit объединяет инструменты, конфиги и материалы автора для разработки с AI. Основной сетап работает на macOS; конфиги подготовлены 4 октября 2026 года.

| Роль в основном стеке | Инструменты |
|---|---|
| Терминал | Ghostty |
| Сессии и панели агентов | Herdr |
| Агенты для работы с кодом | Codex, Claude Code |
| Заметки | Obsidian |
| Редакторы | Neovim, VS Code |
| Файлы в терминале | Yazi |
| Браузер | Zen |

В полном клоне есть настройки Orca и Hunk. Каталог также содержит альтернативные инструменты, плагины Herdr, сторонние скиллы и исследовательские репозитории из видео. Само присутствие в каталоге не является рекомендацией автора.

## Где лежат материалы

`README.md` содержит быстрый старт, `TOOLS.md` каталог, `configs/README.md` перенос конфигов, `skills/README.md` скиллы, `videos/README.md` подборки к видео. У каждого раздела есть прямые ссылки на материалы.

При установке скилла отдельно полный каталог и конфиги остаются в клоне набора. Найди его по пути пользователя. Для рекомендации без локального клона можно прочитать нужный файл в публичном репозитории. Сначала прочитай нужный README, затем только выбранные файлы. Если пользователь хочет установку, читай `setup-ai-stack` из установленной копии, локального клона или публичного репозитория.

## Что учитывать

Настройки являются снимком, а не гарантией совместимости с новой версией. В настройках агентов и shell-фрагменте есть профиль полных разрешений. При переносе нужно сохранить режим пользователя или согласовать его изменение.

JSON Orca служит памяткой для переноса через Settings. Полный профиль приложения не входит в набор. Часть функций Neovim требует личного помощника автора, который не включён. Полная установка на чистую машину не проверена.
