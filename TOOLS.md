# Инструменты

Текущий стек Кирилла Сачкова на macOS и выбранные дополнения. Полный список ссылок из обзора сохранён в [подборке к видео](videos/ai-stack-2026.md).

[Главная](README.md) · [Мои конфиги](configs/README.md) · [Источники](sources/README.md)

## Мой текущий стек

| Инструмент | Для чего использую |
|---|---|
| [Ghostty](https://github.com/ghostty-org/ghostty) | Терминал с темами, шрифтом и клавишами |
| [Herdr](https://github.com/herdrdev/herdr) | Сессии агентов, вкладки и панели |
| [Codex](https://github.com/openai/codex) | Работа с кодом через агента OpenAI |
| [Claude Code](https://github.com/anthropics/claude-code) | Работа с кодом через агента Anthropic |
| [micro](https://github.com/zyedidia/micro) | Редактор по умолчанию в терминале |
| [Yazi](https://github.com/sxyazi/yazi) | Папки, файлы и превью в терминале |

В моём наборе также есть [Neovim](https://neovim.io), [VS Code](https://code.visualstudio.com), [Obsidian](https://obsidian.md) и [Zen](https://github.com/zen-browser/desktop). Они остаются вариантами для редактирования, заметок и браузера.

## Выбранные дополнения

| Инструмент | Для чего подходит |
|---|---|
| [Orca](https://github.com/stablyai/orca) | Параллельные задачи агентов в отдельном приложении |
| [CanvasTTY](https://github.com/howdeploy/CanvasTTY) | Терминалы агентов на бесконечном холсте |

Эти дополнения я выбрал для набора. Обязательной установки всего списка нет.

## Дополнения Herdr

[Navigator](https://github.com/thanhdat77/herdr-navigator) помогает найти проект или сессию. [reviewr](https://github.com/persiyanov/herdr-reviewr) открывает изменения Git для ревью. Обычные настройки и клавиши обоих дополнений находятся в [конфигах Herdr](configs/herdr/README.md).
