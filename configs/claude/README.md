# Claude Code

[settings.json](settings.json) содержит уровень рассуждения модели (`effortLevel`) и настройки разрешений из снимка автора. Настройки конкретной модели нужно сверить с установленной версией и доступным аккаунтом.

Сохрани действующий `~/.claude/settings.json` и объедини выбранные поля. Учитывай настройки текущего проекта и сохраняй свои hooks, разрешения и подключённые инструменты.

Проверь JSON и отображение настроек в приложении. Режим разрешений выбирай отдельно от переноса уровня рассуждения.
