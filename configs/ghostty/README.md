# Ghostty

[Конфиг](config) задаёт Catppuccin Latte/Mocha, JetBrainsMono Nerd Font Mono, размер шрифта 14 и клавиши для работы с Herdr. [Памятка клавиш](cheatsheet.md).

Найди действующий конфиг до переноса. Ghostty читает `config.ghostty` и `config` из XDG-каталога, обычно `~/.config/ghostty/`. На macOS конфиги также могут лежать в `~/Library/Application Support/com.mitchellh.ghostty/` и перекрывать значения из XDG.

Сохрани текущий файл, проверь установленный шрифт и перенеси выбранные строки. В конфиге несколько строк `keybind`; сохраняй их отдельно.

Для перечитывания на macOS нажми Cmd+Shift+,. Часть настроек применяется только к новым окнам. Проверь шрифт, тему и нужные клавиши в новом терминале.
