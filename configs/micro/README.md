# micro

[settings.json](settings.json) содержит обычные настройки редактора Кирилла Сачкова. [Тема](colorschemes/catppuccin-mocha.micro) использует Catppuccin Mocha. Включены перенос длинных строк, отступы из четырёх пробелов, подсветка текущей строки и поиск.

micro является редактором по умолчанию у автора. Если твой редактор уже подходит, сохраняй его. Установка micro необязательна для тем Ghostty и Herdr.

Настройки обычно лежат в `~/.config/micro/`. Проверь `MICRO_CONFIG_HOME`, XDG и параметр `-config-dir`, если они используются. Сохрани действующие файлы. Объедини выбранные поля, а тему помести в `colorschemes/` действующего каталога micro. Значение `colorscheme` должно совпадать с именем темы без `.micro`.

Для изолированной пробы используй временную папку с выбранными настройками и темой:

```bash
micro -config-dir /путь/к/временной/папке /путь/к/тестовому/файлу
```

Проверь тему, перенос строк, отступы и сохранение тестового файла. Внешний буфер обмена из настройки `clipboard` зависит от ОС и доступных команд. Снимок сверён с micro 2.0.15.
