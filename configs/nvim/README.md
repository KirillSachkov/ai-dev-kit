# Neovim

Папка содержит снимок моей конфигурации на [LazyVim](https://github.com/LazyVim/LazyVim). Загрузка lazy.nvim основана на [LazyVim/starter](https://github.com/LazyVim/starter). Копия его [Apache-2.0](LICENSE-LazyVim-starter) сохранена; набор импортов и параметры изменены под мой сетап. Основные файлы: [init.lua](init.lua), [lazy-lock.json](lazy-lock.json), [Lua-модули](lua/).

Сравни папку со своим действующим конфигом, обычно `~/.config/nvim/`. Сохрани текущую папку и выбери нужные модули. Для отдельного знакомства можно использовать отдельный профиль редактора, чтобы сохранить основной.

Корни личных проектов в модуле интерфейса заменены на `~/Projects`. Проверь этот путь перед переносом.

Команда «Места агентов» в [places.lua](lua/kirill/places.lua) требует `herdr-agent-context`. Личный помощник автора не включён в набор. Без него эта команда недоступна; не считай её частью готовой установки.

Синтаксическая проверка Lua не проверяет загрузку всех плагинов. После переноса открой редактор, проверь загрузку и выбранные команды.
