# Hunk

[config.toml](config.toml) содержит настройки оформления и просмотра diff. Сохрани действующий файл и объедини выбранные поля в `~/.config/hunk/config.toml`, если твоя версия использует этот путь.

После переноса открой diff в тестовом репозитории и проверь отображение файлов.
