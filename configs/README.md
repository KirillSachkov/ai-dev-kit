# Мои конфиги

Снимок окружения Кирилла Сачкова на macOS, подготовленный 4 октября 2026 года. [Главная](../README.md) · [Настройка с агентом](../skills/setup-ai-stack/SKILL.md).

| Инструмент | Настройки | Что меняется |
|---|---|---|
| Ghostty | [Перенос](ghostty/README.md), [config](ghostty/config) | Тема, шрифт и клавиши |
| Herdr | [Перенос](herdr/README.md), [config.toml](herdr/config.toml) | Панели, вкладки и плагины |
| Orca | [Памятка](orca/README.md), [settings.json](orca/settings.json) | Оформление, терминал и параметры агентов |
| Codex | [Перенос](codex/README.md), [config.toml](codex/config.toml) | Модель, уровень рассуждения и режим разрешений |
| Claude Code | [Перенос](claude/README.md), [settings.json](claude/settings.json) | Уровень рассуждения и разрешения |
| Neovim | [Перенос](nvim/README.md) | LazyVim, плагины и клавиши |
| Yazi | [Перенос](yazi/README.md) | Работа с файлами и превью |
| Hunk | [Перенос](hunk/README.md), [config.toml](hunk/config.toml) | Оформление diff |
| zsh | [Перенос](zsh/README.md), [ai-tools.zsh](zsh/ai-tools.zsh) | Запуск агентов и Yazi |

Перед переносом сохрани действующие файлы. Выбирай настройки по своей задаче и объединяй их с текущими конфигами. Если файлом управляет другой проект или символическая ссылка, сохрани этот способ управления.

В Codex, Orca и короткой команде `cld` shell-фрагмента есть параметры полных разрешений. Их перенос требует отдельного выбора режима пользователя. Модель и режим обслуживания запросов (`service_tier`) в конфиге Codex отражают профиль автора. Доступность зависит от аккаунта.

В набор не входят ключи доступа, аккаунты, история сессий и полные базы приложений. Пути к личным проектам заменены общими примерами. Полная установка на чистую машину пока не проверена.
