# Herdr

[config.toml](config.toml) использует префикс Ctrl+B, темы Catppuccin и команды для Navigator, reviewr и Yazi. [Клавиши](cheatsheet.md) · [Файлы и ревью](FILES.md).

Настройки обычно лежат в `~/.config/herdr/`. Сохрани текущие файлы и перенеси выбранные поля. В [navigator.toml](navigator.toml) замени корни каталогов на свои.

[plugins.json](plugins.json) перечисляет плагины из снимка. Этот файл служит памяткой и не заменяет внутренний реестр Herdr. Установи [Navigator](https://github.com/thanhdat77/herdr-navigator) и [reviewr](https://github.com/persiyanov/herdr-reviewr) через менеджер плагинов по инструкциям их авторов. Настройки reviewr лежат в [reviewr.toml](reviewr.toml).

Проверь конфиг поддерживаемой твоей версией командой `herdr config check`. Проверь новые вкладки и панели после перечитывания конфига. Команды Yazi работают после отдельной установки Yazi.

[Herdr](https://herdr.dev) · [Все конфиги](../README.md).
