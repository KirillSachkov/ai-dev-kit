# Клавиши Herdr

Сочетания относятся к [конфигу этого набора](config.toml). Ctrl+B является префиксом. Нажми его, отпусти и нажми следующую клавишу.

| Действие | Клавиши после Ctrl+B |
|---|---|
| Справка | ? |
| Панель справа | V |
| Панель снизу | - |
| Панель на весь экран и обратно | Z |
| Закрыть панель | X |
| Новая вкладка | C |
| Следующая или предыдущая вкладка | N или P |
| Список рабочих пространств | W |
| Поиск проектов и сессий через Navigator | T |
| Ревью через reviewr | D |
| Файлы через Yazi | F |
| Перечитать конфиг | Shift+R |
| Отключиться от сессии | Q |

Ctrl+Alt+стрелки переключают панели сразу. Для Cmd+Alt+стрелок используется пересылка из конфига Ghostty.

Navigator и reviewr требуют отдельных плагинов; Yazi должен быть установлен. Остальные клавиши смотри в конфиге и встроенной справке своей версии.
