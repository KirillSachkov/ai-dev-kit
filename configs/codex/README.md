# Codex

[config.toml](config.toml) сохраняет модель и режим разрешений из профиля автора. Поле `model_reasoning_effort` задаёт уровень рассуждения модели. Поле `service_tier` задаёт режим обслуживания запросов. Файл является снимком и не выбирает доступную модель для твоего аккаунта.

Найди свой пользовательский `config.toml`, обычно в `~/.codex/`. Если задан `CODEX_HOME`, используй его. Сохрани файл и объедини выбранные настройки; сохраняй существующие проекты и провайдеры моделей. Также сохраняй подключения MCP, через которые агент использует внешние инструменты.

Автор использует `approval_policy = "never"` и `sandbox_mode = "danger-full-access"`. Переноси эти поля только если сам выбираешь такой режим. При обычном переносе оформления или уровня рассуждения сохраняй свои разрешения, модель и `service_tier`.

Проверь TOML и запуск интерфейса после переноса. Доступность модели проверяется отдельно; запуск оплачиваемой задачи не является обязательной проверкой конфига.
