# Фрагмент zsh

[ai-tools.zsh](ai-tools.zsh) содержит функцию `yy` для запуска Yazi с переходом в выбранную папку, значения EDITOR/VISUAL и короткие команды запуска инструментов. Фрагмент дополняет `.zshrc`.

Проверь используемый `.zshrc`, учитывая `ZDOTDIR`, сохрани его и добавь нужные определения. Команды должны быть установлены отдельно.

Команда `cld` запускает Claude Code с параметром `--dangerously-skip-permissions`. При переносе только файлового менеджера оставь эту команду в стороне. Режим запуска выбирай под свою работу.

Проверь синтаксис командой `zsh -n <путь-к-файлу>`. В новой сессии проверь нужные команды и функцию `yy`.
