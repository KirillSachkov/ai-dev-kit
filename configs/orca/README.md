# Мои настройки Orca

Файл [settings.json](settings.json) содержит выбранные настройки моего профиля Orca 1.4.204.
Снимок содержит выбранные поля раздела settings. Полный `orca-data.json` здесь не используется.

Настройки оформления и терминала переноси через Settings в Orca:

- Системная тема; Catppuccin Mocha для тёмного терминала, Catppuccin Latte для светлого.
- JetBrainsMono Nerd Font Mono, размер 14, line height 1, лигатуры Auto.
- Блочный курсор без мигания; отступы 12; история прокрутки 50 000 строк.
- Копирование выделенного текста; скрытие мыши при наборе; Option как Alt на macOS.
- Diff Side by side; список файлов List.
- Codex как агент по умолчанию; карточки worktree Compact; порядок вкладок MRU по последнему использованию.
- Native Chat и Structured Native Chat выключены в этом профиле.

В JSON сохранены точные значения этих полей и параметры запуска агентов.
`agentDefaultArgs` содержит мой режим полных разрешений для нескольких агентов.
Выбери свои параметры запуска, если нужен другой режим.

JSON не является подтверждённым файлом автоматического импорта Orca.
Не заменяй им базу приложения. Аккаунты, токены, env, pairing, SSH, проекты, история и автомации исключены.
