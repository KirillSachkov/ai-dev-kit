## Документация и оригиналы

| Материал | Когда открыть |
|---|---|
| [Ghostty Configuration](https://ghostty.org/docs/config) | Найти конфиг терминала и сверить параметры |
| [Herdr Configuration](https://herdr.dev/docs/configuration/) | Настроить темы, клавиши и строки sidebar |
| [Navigator](https://github.com/thanhdat77/herdr-navigator), [reviewr](https://github.com/persiyanov/herdr-reviewr) | Установить публичные дополнения Herdr |
| [micro](https://github.com/zyedidia/micro/tree/master/runtime/help), [Catppuccin для micro](https://github.com/catppuccin/micro) | Настроить редактор и проверить оригинальную тему |
| [Yazi Configuration](https://yazi-rs.github.io/docs/configuration/overview/), [публичные плагины](https://github.com/yazi-rs/plugins) | Сверить конфиги и зависимости превью |
| [Matt Pocock skills](https://github.com/mattpocock/skills) | Выбрать скиллы и подключить pipeline по upstream |

Инструкции подключения и технические параметры могут меняться. Перед настройкой сверяй нужный раздел оригинальной документации со своей версией.
