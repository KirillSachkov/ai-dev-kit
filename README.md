## Начать с агентом

Клонируй репозиторий через Git:

```bash
git clone https://github.com/KirillSachkov/ai-dev-kit.git
```

Или скачай ZIP через кнопку Code на GitHub. Открой папку в своём агенте и отправь запрос:

```text
Прочитай README.md и AGENTS.md. Используй главный скилл
skills/sachkov-ai-kit/SKILL.md, чтобы помочь мне выбрать инструменты
и материалы из набора Кирилла Сачкова под мои задачи.
```

Для настройки окружения добавь, что хочешь перенести. Например:

```text
Хочу настроить Ghostty и Herdr на macOS. Codex уже установлен,
редактор оставлю VS Code. Используй skills/setup-ai-stack/SKILL.md.
Сохрани мои текущие настройки и перенеси только выбранные инструменты.
```

Главный скилл помогает выбрать материалы и объясняет, зачем нужны инструменты. Скилл настройки проверяет окружение, адаптирует конфиги и проверяет результат. Они также доступны как [отдельные устанавливаемые скиллы](skills/README.md#установка-скиллов).

## Конфиги

В наборе лежат конфиги для 9 компонентов моего окружения. Снимок подготовлен 4 октября 2026 года. Описание переноса и зависимости находятся в [configs/README.md](configs/README.md).

Настройки Codex, Orca и shell-фрагмент содержат мой режим полных разрешений. Агент должен сохранить твой режим или согласовать его изменение. Аккаунты, ключи и история сессий в набор не входят.

Полная установка на чистую машину пока не проверена. Настройки Orca служат памяткой для переноса через интерфейс приложения.

## Дополнять набор

Новый инструмент добавляй в `TOOLS.md`, конфиги клади в `configs/<инструмент>/`, скилл в `skills/<название>/`. Материалы нового видео добавляй в `videos/`. Обновляй ссылки в README соответствующего раздела.

Команда `python3 scripts/check.py` проверяет навигацию, структуру скиллов, JSON, TOML и несколько известных шаблонов секретов и личных путей. Нужен Python 3.11 или новее. Проверка работает локально без сетевых запросов. После изменения скриптов запусти `python3 -m unittest discover -s tests`.
